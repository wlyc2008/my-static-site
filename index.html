Cloudflare Pages

连接 Git，推送即构建

这是一个零依赖的纯静态示例页面。仓库推送到 Git 后，Cloudflare Pages 会自动构建产物、 部署到全球边缘节点，并为每个分支生成独立的预览地址。

查看部署步骤 了解页面能力

页面包含哪些内容

纯静态资源

index.html 与 styles.css 两个文件，无构建步骤、无依赖安装，Pages 直接按静态文件发布。

响应式布局

使用 CSS Grid 与 Flexbox，桌面端三列、移动端单列，无需任何 CSS 框架。

自定义 404

仓库中的 404.html 会被 Pages 自动识别为站点级错误页。

边缘缓存

静态资源缓存在 Cloudflare 边缘节点，命中缓存的请求几乎没有回源开销。

免费额度

Pages 免费套餐提供每月构建次数与带宽额度，个人项目与小型站点足够使用。

自定义域名

在 Pages 项目的 Custom domains 中添加域名，DNS 记录会自动配置并自动签发证书。

部署到 Cloudflare Pages

  1. 1. 推送代码到 Git 仓库

    在项目目录执行 git init、git add .、git commit，再关联远端仓库并推送。

  2. 2. 在 Dashboard 新建 Pages 项目

    登录 Cloudflare Dashboard，进入 Workers & Pages → Create application → Pages → Connect to Git。

  3. 3. 选择仓库与分支

    授权 GitHub / GitLab 账号，选择存放本项目的仓库和生产分支（通常是 main）。

  4. 4. 填写构建设置

    Framework preset 选 None，Build command 留空，Build output directory 填 .（本项目无构建产物目录）。

  5. 5. 保存并部署

    点击 Save and Deploy。后续每次推送都会自动触发构建，非生产分支会生成 *.pages.dev 预览地址。
